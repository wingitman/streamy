# Delbysoft TUI Blueprint

Generated projects must preserve responsive measured layout, wrapped
variable-height scrolling, keyboard and mouse interaction, TOML configuration,
shared Delbysoft themes with a `T` theme picker, live theme reload, asynchronous
external commands, contextual hints, and the top-right clickable Delbysoft logo
opening https://delbysoft.com.
# Generated baseline note

This project targets Bubble Tea v2, Lip Gloss v2, and Bubbles v2. The starter
implements config migration, themes, editor reload, clipboard, history,
update/rollback primitives, cross-platform installers, measured display-cell
layout, and layout-derived mouse hitboxes. Domain projects must retain these
behaviors while extending the generated baseline.
